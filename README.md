# Эмулятор командной строки UNIX (вариант 7)

Консольное приложение на Java для Windows 11. Проект разрабатывается по пяти
этапам; каждый этап сохранён отдельным коммитом. Виртуальная файловая система
и команды будут добавлены в следующих этапах.

## Сборка и запуск

Нужен JDK 17 или новее. На Windows запустите `run.bat`, либо
`powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1`.
Скрипт компилирует исходники в игнорируемую папку `build` и запускает программу.

## Функции этапа 1

- Приглашение формируется из реального имени пользователя и имени компьютера.
- Строка делится на слова с поддержкой одинарных и двойных кавычек и экранирования.
- Переменные реальной ОС раскрываются как `$NAME` и `${NAME}`; в одинарных
  кавычках раскрытия нет. Неизвестная переменная даёт пустую строку.
- `ls` и `cd` пока выводят имя и список полученных аргументов.
- `exit` завершает сеанс. Неизвестная команда и некорректные кавычки
  показывают ошибки.

## Пример

```text
username@hostname:~$ ls "$USER" 'literal $USER'
ls [значение USER, literal $USER]
username@hostname:~$ cd /tmp
cd [/tmp]
username@hostname:~$ invalid
invalid: command not found
username@hostname:~$ exit
```

Примеры можно повторить в интерактивном режиме. Описание следующих этапов,
параметров и тестов будет дополнено по мере разработки.
