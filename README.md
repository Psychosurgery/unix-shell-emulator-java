# Эмулятор командной строки UNIX (вариант 7)

Консольное приложение на Java для Windows 11. Проект разрабатывается по пяти
этапам; каждый этап сохранён отдельным коммитом. Виртуальная файловая система
и команды будут добавлены в следующих этапах.

## Сборка и запуск

Нужен JDK 17 или новее. На Windows запустите `run.bat`, либо
`powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1`.
Скрипт компилирует исходники в игнорируемую папку `build` и запускает программу.

## Функции этапа 1

- Приглашение формируется из реального имени пользователя и имени компьютера.
- Строка делится на слова с поддержкой одинарных и двойных кавычек и экранирования.
- Переменные реальной ОС раскрываются как `$NAME` и `${NAME}`; в одинарных
  кавычках раскрытия нет. Неизвестная переменная даёт пустую строку.
- `ls` и `cd` пока выводят имя и список полученных аргументов.
- `exit` завершает сеанс. Неизвестная команда и некорректные кавычки
  показывают ошибки.

## Настройки этапа 2

- `--vfs ПУТЬ` задаёт путь к каталогу VFS. На этом этапе путь только выводится
  при запуске; загрузка каталога появится на этапе 3.
- `--script ПУТЬ` запускает команды из текстового файла UTF-8. Эмулятор
  показывает каждую строку с приглашением и её результат, завершает работу
  после первой ошибки с кодом 1. Без скрипта запускается интерактивный режим.
- При запуске отображаются оба параметра, в том числе незаданные. Ошибочные
  аргументы запуска завершают процесс с кодом 2.

Проверить сочетания параметров можно через `tests\scripts\stage2-default.bat`,
`tests\scripts\stage2-vfs.bat`, `tests\scripts\stage2-script.bat` и
`tests\scripts\stage2-both.bat`. Проверка остановки при ошибке:
`run.bat --script tests\fixtures\stage2-error.txt`.

## VFS этапа 3

Параметр `--vfs` указывает на существующий каталог диска. При запуске
содержимое каталога целиком загружается в память, а источник больше не
изменяется. Если параметр не задан, создаётся пустой виртуальный корень.
Отсутствующий путь и неверный формат (например, обычный файл вместо каталога
или символическая ссылка внутри) вызывают ошибку до начала работы.

Примеры источников: `tests\fixtures\vfs\minimal` (один файл),
`tests\fixtures\vfs\several` (несколько файлов), `tests\fixtures\vfs\deep` (более трёх
уровней). Их загрузку проверяют `tests\scripts\stage3-*.bat`; сценарии
`tests\fixtures\stage3-success.txt` и `tests\fixtures\stage3-error.txt` проверяют
сохранённые команды, переменные и остановку после ошибки. На этом этапе
`ls` и `cd` остаются заглушками; логика работы с VFS появится на этапе 4.

## Основные команды этапа 4

`ls [-a] [-l] [--] [путь...]` показывает содержимое каталога или имя файла.
`-a` включает скрытые имена, `-l` даёт упрощённый формат с типом и размером.
Относительные и абсолютные пути поддерживают `.`, `..` и `~` (виртуальный
корень). `cd [путь]` меняет виртуальный рабочий каталог; без аргументов
возвращается в корень, `cd -` возвращается в предыдущий каталог.
`cat файл...` выводит содержимое файлов UTF-8. `date` показывает локальное
время, `date -u` — UTC. `whoami` показывает имя реального пользователя ОС.
Команды с ошибочным числом аргументов, неизвестной опцией и неверным путём
показывают ошибку; стартовый сценарий после неё прекращается.

Полный успешный сценарий: `tests\scripts\stage4-success.bat`. Набор сценариев с
ошибками: `tests\scripts\stage4-errors.bat`. Автоматические проверки:
`powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test.ps1`.

## Пример

```text
username@hostname:~$ ls /home/user
projects
todo.txt
username@hostname:~$ cd /home/user
username@hostname:~/home/user$ cat todo.txt
Learn shell commands.
username@hostname:~$ invalid
invalid: command not found
username@hostname:~$ exit
```

Пример предполагает источник `tests\fixtures\vfs\deep` и использует условные
имя пользователя и компьютера. Следующий этап добавит `mv`.
